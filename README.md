One funny line, judged two at a time by GLM-5.3-flash. The entry:

> I told my agent to think outside the box, so it filed a ticket against the box and escalated it to Monday.

`main.ts` checks the line against the 1–200 character gate and writes it to `entry.txt` unchanged.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/lo-out node main.ts
```
